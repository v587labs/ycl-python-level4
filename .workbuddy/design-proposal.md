# YCL Python 四级互动课件 — UI 设计方案

> 版本：v1.0 | 状态：设计稿 | 覆盖页面：首页、课时页（含教师/学生模式）

---

## 1. 设计目标与美学方向

### 1.1 设计目标

- **建立信任感**：课件面向 8-12 岁青少年，颜色和字体传达专业但不严肃的氛围
- **降低认知负担**：信息层次清晰，关键操作一目了然，无需家长陪同也能自主使用
- **保持专注**：每个课时都有明确的学习路径，不会被无关元素分心
- **符合品牌调性**：橙色活泼 + 青绿色清新，给学习一种「探险」的感觉

### 1.2 美学方向：温暖克制 (Warm Minimal)

不追随 AI 配色惯例（青蓝渐变、霓虹感），而是以暖白为基底，橙色为主调，青绿色作为功能区分色。整体感觉：像一个认真设计过的练习册，而不是一个 AI 生成网页。

| 警告色 | `#FDCB6E` | 同上 | 正在进行、注意事项 |

```
答对   → 薄荷绿背景

```

## 3. 字体系统

### 3.1 字体选择

| 用途 | 字体 | 备选 |
|------|------|------|
| **标题字体** | Nunito | system-ui, sans-serif |
| **正文字体** | Nunito | system-ui, sans-serif |
| **代码字体** | Fira Code | Monaco, Consolas |

> **为什么用 Nunito**：Google Fonts 上最接近「活泼但不过于童稚」的字体，无衬线、圆润，适合教育类应用。字重 400 用于正文，600 用于标题和按钮。

### 3.2 字体尺度

```
h1 (页面大标题)    28px / 700
h2 (章节标题)      22px / 700
h3 (课时标题)      18px / 600
body (正文)        15px / 400
label (标签)       13px / 500
caption (说明)     12px / 400
code (代码)        14px / 400 (Fira Code)
```

## 4. 首页设计

### 4.1 布局结构

```
┌─────────────────────────────────────────────────────┐
│  [Logo + 标题]              [进度环] [导入] [导出]   │  ← 顶栏
├─────────────────────────────────────────────────────┤
│                                                     │
│         YCL Python 四级互动课件                      │  ← 主标题区
│         基于《人工智能编程水平测试》教材              │
│         ════════════════════                        │  ← 进度条
│         已完成 12/21 课时 · 总体进度 57%             │
│                                                     │
├─────────────────────────────────────────────────────┤
│  [序章            ══════════════════════════════]   │  ← 章节标题
│    [课时卡片×3 网格排列]                             │
├─────────────────────────────────────────────────────┤
│  [第1章 Python语言基本语法                           │
│    [课时卡片×3 网格排列]                             │
├─────────────────────────────────────────────────────┤
│  ... (按章节依次排列)                                │
├─────────────────────────────────────────────────────┤
│           [导出JSON] [导入JSON] [导出CSV]             │  ← 操作区
└─────────────────────────────────────────────────────┘
```

### 4.2 顶栏设计

- **左侧**：Logo 图形（Python 蛇形 icon + YCL 文字）
- **右侧**：圆形进度环（SVG） + 两个 icon 按钮（导入/导出）
- 顶栏固定在顶部，高度 64px，背景 `#FFFBF5`

### 4.3 章节标题区

- 左侧装饰线 + 章节名称 + 右侧装饰线（虚线分隔）
- 章节名用 `h2 22px / 700`，整体在视觉上形成分区

### 4.4 课时卡片

**尺寸**：宽度响应式，最小 280px，最大 1fr（3 列）
**结构**：
- 左侧 4px 状态色条（已完成=绿，进行中=橙，未开始=灰）
- 图标区（40×40 圆角方块）+ 课时编号 + 标题
- 副标签：章节名 · 预计时长 · 难度星级
- 底部状态徽章

**三种状态视觉**：
- **已完成**：绿色左边框 + 绿色徽章 + 图标区浅绿底
- **进行中**：橙色左边框 + 橙色徽章 + 图标区浅橙底 + 脉冲动画
- **未开始**：灰色左边框 + 灰色徽章 + 图标区浅灰底

## 5. 课时页设计

### 5.1 布局结构

```
┌─────────────────────────────────────────────────────┐
│  [←返回] [Lesson 3 图标] 课时标题                    │  ← 顶栏
│           章节名 · 难度星级      [教师/学生 切换]    │
├────────────────────┬────────────────────────────────┤
│                    │                                │
│   侧边导航         │   主内容区                      │
│   ├─ 概念卡片      │   （教师模式 or 学生模式内容）   │
│   ├─ 常见错误      │                                │
│   ├─ 动手练习      │                                │
│   └─ 测验          │                                │
│                    │                                │
├────────────────────┴────────────────────────────────┤
│  [当前目标提示]              [返回教师页] [返回首页]  │  ← 底部栏
└─────────────────────────────────────────────────────┘
```

### 5.2 顶栏设计

- 高度 64px，白色背景 + 底部细边框
- 左侧：返回按钮（圆形）+ 课时编号徽章 + 标题
- 右侧：模式标签（教师=紫色，学生=绿色）+ 切换按钮

### 5.3 侧边导航（桌面端）

- 固定在左侧，宽度 240px
- 每个 section 一个可折叠面板
- 当前 section 高亮显示
- 移动端：变为顶部 tab 切换

### 5.4 教师模式内容

**概念卡片（ConceptCard）**：
- 卡片式布局，标题 + 定义 + 插图 + 示例代码
- 可展开查看完整内容（默认折叠）

**常见错误卡片（MistakeCard）**：
- 错误代码红色背景
- 正确代码绿色背景
- 解释文字灰色

### 5.5 学生模式内容

**随堂测验（Quiz）**：
- 题目进度指示（3/4）
- 单选/多选题，每个选项独立卡片
- 选择后立即显示对/错反馈 + 解析
- 答对：绿色背景 + ✓图标；答错：红色背景 + ✗图标

**编程挑战（CodeEditor）**：
- 带语法高亮的代码编辑器（Prism.js）
- 运行按钮（橙色）+ 输出区
- Pyodide 实时执行，显示 console 输出

## 6. 组件规范

### 6.1 按钮

| 类型 | 样式 |
|------|------|
| **主按钮** | 珊瑚橙底 `=#FF6B35`，白字，12px 圆角，hover 时加阴影上移 1px |
| **次按钮** | 透明底，1px 灰色边框，12px 圆角，hover 时边框变橙 |
| **幽灵按钮** | 无边框，橙色字，hover 时加橙色下划线 |
| **危险按钮** | 红色底 `=#E74C3C`，白字 |

### 6.2 徽章 / 标签

- `已完成`：浅绿底 + 薄荷绿字 + ✓ 图标
- `进行中`：浅橙底 + 珊瑚橙字 + ⟳ 图标
- `未开始`：浅灰底 + 灰色字 + ○ 图标
- 圆角 8px，padding 4px 12px

### 6.3 课时卡片

- 白色背景，16px 圆角
- hover 时：上移 2px + 浅阴影
- 左侧状态色条 4px 宽
- 内部间距：16px

### 6.4 概念卡片

- 白色背景，12px 圆角
- 标题区：Nunito 600 + 灰色分隔线
- 展开/折叠动画（高度过渡 300ms ease）

### 6.5 Quiz 选项

- 默认：浅灰底 + 空心圆
- hover：边框加橙色
- 选中（未判）：橙色边框 + 橙色圆点
- 答对：绿色底 + ✓ + 绿色边框
- 答错：红色底 + ✗ + 红色边框

### 6.6 代码编辑器

- 深色背景 `#1E1E1E`（VS Code 风格）
- 语法高亮（Fira Code）
- 行号显示
- 运行按钮（橙色）在右上角
- 输出区在下方，半透明深色背景

### 6.7 进度条

- 高度 8px，12px 圆角
- 背景：浅灰底
- 填充：珊瑚橙渐变
- 动画：从 0 过渡到目标值，500ms ease-out

### 6.8 顶栏进度环

- 直径 48px，线宽 4px
- 背景：浅灰底
- 进度：珊瑚橙
- 中心显示数字百分比

## 7. 动画规范

| 场景 | 动画 | 参数 |
|------|------|------|
| 页面加载 | 淡入 + 上移 | opacity 0→1, translateY 8px→0, 300ms ease-out |
| 卡片 hover | 上浮 | translateY 0→-2px, 200ms ease-out |
| 按钮点击 | 按压 | scale 1→0.97, 100ms ease-in |
| 模式切换 | 颜色过渡 | 300ms ease |
| 进度条填充 | 宽度动画 | 500ms ease-out |
| 课程卡片 | 状态徽章切换 | 300ms ease |
| 侧边导航展开 | 高度折叠 | 300ms ease-in-out |
| Quiz 选项反馈 | 背景色渐变 | 200ms ease |

## 8. 响应式策略

### 8.1 断点

| 断点 | 宽度 | 布局调整 |
|------|------|---------|
| Mobile | < 640px | 单列，卡片全宽，侧边导航变为底部 tab |
| Tablet | 640-1023px | 2 列课时卡片，侧边导航保留 |
| Desktop | ≥ 1024px | 3 列课时卡片，侧边导航固定 |

### 8.2 移动端优化

- 顶栏简化：进度环隐藏，显示文字进度
- 底部栏固定：方便拇指操作
- 课时卡片：tap 目标 ≥ 44px
- 侧边导航：变为顶部水平 tab 滚动
