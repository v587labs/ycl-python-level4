## 晚间更新：修复进度不更新 Bug

### 问题描述
用户做完练习后进度条没有变化，重新进入课时后选择题和编程题的完成状态丢失。

### 根本原因
`StudentPage.jsx` 每次渲染时用 `useState` 初始化空状态（`quizCompleted: false`, `quizScore: 0` 等），没有从 localStorage 恢复已保存的进度。

### 修复方案
在 `StudentPage` 组件中添加 `useEffect`，在页面加载时从 AppContext 的 `getProgress()` 读取已保存的进度并恢复状态：

```jsx
useEffect(() => {
  const lessonProgress = getProgress(lesson.id);
  if (lessonProgress) {
    if (lessonProgress.quizScore !== undefined) {
      setQuizScore(lessonProgress.quizScore);
    }
    if (lessonProgress.quizCompleted) {
      setQuizCompleted(true);
    }
    if (lessonProgress.codingPassed) {
      setCodingCompleted(true);
    }
  }
}, [lesson.id, getProgress]);
```

### 文件修改
- `src/pages/StudentPage.jsx` - 添加进度恢复逻辑
- 构建验证通过
